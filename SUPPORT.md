## Community Support

If you need help using `EricksonLopez.Pagination`, you can:

- [Open an Issue](https://github.com/ericksonlopezf/dotnet-pagination/issues) for bugs or feature requests.
- [Start a Discussion](https://github.com/ericksonlopezf/dotnet-pagination/discussions) for questions, ideas, or general help.
- **Direct Email Support**: Contact the project maintainer at [ericksonlopezf@gmail.com](mailto:ericksonlopezf@gmail.com).
- **Official Website**: [https://ericksonlopez.dev/pagination](https://ericksonlopez.dev/pagination)

## Versioning

This project follows [Semantic Versioning](https://semver.org/). Version management is handled by [MinVer](https://github.com/adamralph/minver) based on git tags (format: `v*.*.*`). Only the latest release on `main` is officially supported with security patches. See [SECURITY.md](SECURITY.md) for the supported versions table.
